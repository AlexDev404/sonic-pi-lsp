## Correctness

### invalid-bpm

Use_bpm or with_bpm with a tempo of zero or less.

- Default: `error`
- In `.splintrc`: `invalid-bpm: warning`

### invalid-opt-value

Literal opt values a synth, FX or sample rejects (release: -1, cutoff: 200).

Uses the validations in Sonic Pi's own synth definitions, the same checks the server makes when use_arg_checks is on.

- Default: `error`
- In `.splintrc`: `invalid-opt-value: warning`

### live-loop-name

Live_loops without a name.

- Default: `error`
- In `.splintrc`: `live-loop-name: warning`

### live-loop-no-sleep

Live_loops that never sleep or sync (Sonic Pi stops them with an error).

A live_loop body must advance time with sleep, sync or a function that does (play_pattern_timed, or your own define that sleeps). Calls to functions the linter cannot see into count as sleeping.

- Default: `error`
- In `.splintrc`: `live-loop-no-sleep: warning`

### loop-no-sleep

Loop do ... end and while true loops that never sleep (they lock up the run).

- Default: `error`
- In `.splintrc`: `loop-no-sleep: warning`

### negative-sleep

Sleep or wait with a negative time.

- Default: `error`
- In `.splintrc`: `negative-sleep: warning`

### syntax

Ruby syntax errors (the code would not run at all).

Sonic Pi code is Ruby. A syntax error stops the whole buffer from running; the most common cause is a `do` with no matching `end`.

- Default: `error`
- In `.splintrc`: `syntax: warning`

### unknown-chord

Chord names Sonic Pi does not have (chord :e, :minr).

- Default: `error`
- In `.splintrc`: `unknown-chord: warning`

### unknown-fn-opt

Opts that a Sonic Pi function does not document (live_loop :x, sycn: ...).

- Default: `warning`
- In `.splintrc`: `unknown-fn-opt: warning`

### unknown-fx

With_fx with an FX Sonic Pi does not have.

- Default: `error`
- In `.splintrc`: `unknown-fx: warning`

### unknown-note

Note names Sonic Pi cannot read (play :h4, note: :cs).

- Default: `error`
- In `.splintrc`: `unknown-note: warning`

### unknown-opt

Opts a synth, FX or sample does not take, which Sonic Pi silently ignores (cuttoff:, amp_sldie: ...).

play and friends are checked against the current synth (as set by use_synth or with_synth), with_fx against the FX, sample against the sample player. Inside define, where the synth is not known, opts are checked against every synth. Sonic Pi does not complain about these: the opt just does nothing, which is usually a typo or an opt meant for another synth.

- Default: `warning`
- Options: `allow` (default `[]`)
- In `.splintrc`: `unknown-opt: { severity: warning, allow: [] }`

### unknown-sample

Built-in samples (sample :name) that do not exist.

- Default: `error`
- In `.splintrc`: `unknown-sample: warning`

### unknown-scale

Scale names Sonic Pi does not have (scale :c, :majr).

- Default: `error`
- In `.splintrc`: `unknown-scale: warning`

### unknown-synth

Use_synth, with_synth and synth with a synth Sonic Pi does not have.

Checked against the synths of the bundled Sonic Pi. An FX name gets a hint to use with_fx.

- Default: `error`
- In `.splintrc`: `unknown-synth: warning`

## Suspicious code

### amp-too-high

Very loud literal amp: values, which distort.

- Default: `info`
- Options: `max` (default `5`)
- In `.splintrc`: `amp-too-high: { severity: warning, max: 5 }`

### duplicate-live-loop

Two live_loops with the same name (only the last one plays).

- Default: `warning`
- In `.splintrc`: `duplicate-live-loop: warning`

### run-file-missing

Run_file with a path that does not exist.

- Default: `warning`
- In `.splintrc`: `run-file-missing: warning`

### sample-path-missing

Sample "path" where the file or folder does not exist (or is an mp3).

- Default: `warning`
- Options: `search` (default `[]`)
- In `.splintrc`: `sample-path-missing: { severity: warning, search: [] }`

### shadowed-builtin

Define or def that replaces one of Sonic Pi's own functions.

- Default: `warning`
- In `.splintrc`: `shadowed-builtin: warning`

### sync-without-cue

Sync on a name that nothing in the file cues.

Fine when the cue comes from another buffer, OSC or MIDI; a typo otherwise.

- Default: `info`
- In `.splintrc`: `sync-without-cue: warning`

### undefined-function

Calls to functions that are not Sonic Pi's, Ruby's, or defined in the file.

Functions defined in ~/.sonic-pi/config/init.rb count as defined when use_init is on. List others (from run_file, say) under globals in .splintrc.

- Default: `warning`
- In `.splintrc`: `undefined-function: warning`

### unreachable-code

Code after an endless loop do ... end, which never runs.

loop do ... end blocks the thread it runs in. Use live_loop or in_thread to run code beside it.

- Default: `warning`
- In `.splintrc`: `unreachable-code: warning`

### unused-define

Functions defined with define that are never called.

- Default: `info`
- In `.splintrc`: `unused-define: warning`

## Performance

### fx-in-live-loop

With_fx directly inside a live_loop, which builds a new FX every time round.

Each with_fx starts a new FX synth. Inside a live_loop that happens on every iteration, which costs CPU and can glitch. Wrap the live_loop in the with_fx instead.

- Default: `info`
- In `.splintrc`: `fx-in-live-loop: warning`

### nested-live-loop

Live_loop defined inside another loop (redefined on every iteration).

- Default: `warning`
- In `.splintrc`: `nested-live-loop: warning`

### thread-in-loop

In_thread inside a loop without a name: a new thread every iteration.

- Default: `info`
- In `.splintrc`: `thread-in-loop: warning`

## Compatibility

### deprecated

Functions Sonic Pi no longer documents (sample packs).

- Default: `warning`
- In `.splintrc`: `deprecated: warning`

### desktop-only

Functions that need the desktop editor (load_buffer, load_example).

- Default: `warning`
- In `.splintrc`: `desktop-only: warning`

## Style

### comment-space

Comments without a space after #.

- Default: `off` (fixed by `sonicpi lint --fix`)
- In `.splintrc`: `comment-space: warning`

### final-newline

Files that do not end with a newline.

- Default: `info` (fixed by `sonicpi lint --fix`)
- In `.splintrc`: `final-newline: warning`

### indentation

Indentation that differs from Sonic Pi's auto-align (what the desktop does on Run).

Fix it with `sonicpi fmt -w FILE` or `sonicpi lint --fix`.

- Default: `info` (fixed by `sonicpi lint --fix`)
- In `.splintrc`: `indentation: warning`

### line-length

Lines longer than max.

- Default: `off`
- Options: `max` (default `120`), `ignore_comments` (default `false`)
- In `.splintrc`: `line-length: { severity: warning, max: 120, ignore_comments: false }`

### max-lines

Files longer than max lines.

- Default: `off`
- Options: `max` (default `500`)
- In `.splintrc`: `max-lines: { severity: warning, max: 500 }`

### max-nesting

Blocks nested more than max deep.

- Default: `off`
- Options: `max` (default `5`)
- In `.splintrc`: `max-nesting: { severity: warning, max: 5 }`

### no-tabs

Tab characters used for indentation.

- Default: `info` (fixed by `sonicpi lint --fix`)
- Options: `width` (default `2`)
- In `.splintrc`: `no-tabs: { severity: warning, width: 2 }`

### trailing-whitespace

Spaces or tabs at the end of a line.

- Default: `info` (fixed by `sonicpi lint --fix`)
- In `.splintrc`: `trailing-whitespace: warning`
